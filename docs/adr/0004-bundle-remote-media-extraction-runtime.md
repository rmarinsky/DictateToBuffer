# Bundle the remote media extraction runtime

Diduny will ship the complete runtime required to retrieve supported remote media and captions instead of requiring Homebrew or user-installed tools. Runtime updates will ship through Diduny's existing signed application update channel rather than a separate self-updater. This makes authenticated YouTube transcription a self-contained supported feature, while accepting increased app size plus responsibility for signing, notarization, third-party licenses, compatibility updates, and extraction regressions through Diduny's release process.
